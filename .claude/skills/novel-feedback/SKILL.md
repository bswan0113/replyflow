이 스킬은 `docs/phases/09-feedback.md`의 절차를 그대로 따른다.

절차 요약(자세한 내용은 `docs/phases/09-feedback.md` 참고):

1. 정량 데이터(조회수/댓글수/선호작수)를 수집한다 — 가능하면 직접 조회, 없으면 사용자 입력. `07-feedback/stats.md`에 기록.
2. 정성 피드백(댓글 등)을 수집하고 `feedback-analyst` 서브에이전트로 분류·요약받는다.
3. 정량+정성 요약을 사용자에게 보고한다.
4. 방향 수정 여부를 사용자가 결정한다 — 불필요하면 6단계로 복귀, 필요하면 해당 update 서브에이전트(세계관/플롯/캐릭터) 호출 또는 근본적 전환이면 시놉시스 직접 수정.
5. `07-feedback/log.md`에 이번 라운드를 기록한다. `project.yaml`은 `status`를 9로 유지하고 `stage_history`에 라운드를 추가한다(반복 재진입).
