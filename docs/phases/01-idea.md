# 1단계 — 아이디어 구축

## 목표

사용자가 떠올린 장면이나 소재 하나를 받아, 개발할 가치가 있는지 가볍게 점검한 뒤 시놉시스 수준까지 발전시키고, 플랫폼·분량·사업성에 대한 가결정(provisional)까지 마친다. 기존 파이프라인 표의 옛 2단계(평가)는 별도 진입점 없이 이 단계 안의 "1차평가"와 "최종평가" 두 지점으로 흡수되어 있다.

플랫폼·분량·사업성 판단은 어디까지나 **가결정**이다. 세계관(3단계)·캐릭터(4단계)가 확정된 뒤 5단계(플랫폼 선정)에서 반드시 재검토해 확정한다. 이 문서만 보고는 5단계에서 무엇을 뒤집어도 되는지 헷갈릴 수 있으니, 1단계 산출물에는 항상 "가결정"이라는 딱지를 붙여 남긴다.

## 입력

사용자가 자유형식으로 전달하는 장면·소재·모티프 텍스트. 형식 제약 없음 — 한 문장짜리 이미지여도 되고, 장면 묘사여도 되고, "이런 설정이면 어떨까" 정도의 메모여도 된다.

## 절차

### 1. 소재 수집
사용자가 전달한 내용을 그대로 기록해둔다. 이 시점에서 임의로 각색하거나 확장하지 않는다.

### 2. 1차평가 (`idea-evaluator` 호출, 모드: 1차)
소재 자체가 더 진행할 가치가 있는지 가볍게 판단한다. 통과/보완요청 두 갈래로만 답하며, 반려가 아니라 "무엇을 더 생각해오면 좋을지" 제안으로 응답한다. 명백히 소재가 너무 빈약하거나(한 줄 이상으로 확장할 갈등이 없음) 이미 흔한 클리셰의 반복이기만 하면 보완요청, 아니면 통과.

### 3. 시놉시스 기획
1차평가를 통과한 소재를 아래 템플릿으로 발전시킨다.

```
- 로그라인 (1~2문장)
- 장르/톤
- 주인공과 핵심 욕망/결핍
- 핵심 갈등 (외적/내적)
- 세계관 스케치 (한 문단, 상세 설정은 3단계에서)
- 결말 방향 (확정 아님, 지향점)
- 차별점 (비슷한 기존 작품과 무엇이 다른가)
```

### 4. 플랫폼·분량·사업성 가결정 논의
시놉시스를 바탕으로 아래 세 가지를 사용자와 논의해 가결정한다.

- **후보 플랫폼**: 장르/톤에 맞는 플랫폼 후보를 제시 (문피아/카카오페이지/네이버시리즈 등). 이 시점에는 각 플랫폼의 최신 연재규칙까지 조사하지 않는다 — 그건 5단계(`platform-scout`)의 일. 여기서는 "어울릴 만한 후보"만 좁힌다.
- **분량 유형**: `serial`(연재) 또는 `novella`(중단편) 중 지향점.
- **사업성**: `hobby`(취미용) / `game_adaptation`(추후 게임 스토리로 발전) / `paid_serial`(유료 판매용) 중 지향점.

### 5. 사용자 컨펌
시놉시스 + 가결정 내용을 정리해 사용자에게 보여주고 승인을 받는다. 이 컨펌 없이 다음 단계로 진행하지 않는다.

### 6. 최종평가 (`idea-evaluator` 호출, 모드: 최종)
시놉시스와 가결정 전체를 종합평가한다. 시장성(가결정 플랫폼과의 적합도), 차별성, 실현가능성(작가가 완주 가능한 스케일인가), 사업성 정합성(고른 사업성과 시놉시스가 실제로 맞는가) 네 항목을 판정하고 종합판정(진행/재검토)을 낸다. 재검토 판정이면 3단계로 넘어가지 않고 4번(가결정 논의) 또는 3번(시놉시스)으로 되돌아간다.

## 산출물

- `projects/<slug>/01-idea/synopsis.md` — 시놉시스 + 가결정(플랫폼 후보/분량/사업성) 기록
- `projects/<slug>/01-idea/evaluation.md` — 1차평가 결과 + 최종평가 결과(항목별 판정 포함)

## `project.yaml` 갱신

최종평가를 통과하면:

```yaml
status: 3
platform:
  target: [...]        # 논의된 후보들
  provisional: "..."    # 가장 유력한 후보 하나
business_model: "..."   # hobby | game_adaptation | paid_serial
length_type: "..."      # serial | novella
stage_history:
  - stage: 1
    entered_at: "..."
    note: "시놉시스+가결정 완료, 최종평가 통과"
```
