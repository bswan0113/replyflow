# 8단계 — 게시

## 목표

7단계에서 만든 게시 필수요소(`essentials.md`)를 실제로 확정 플랫폼에 게시한다. 이 단계는 판단이나 생성이 필요 없다 — 이미 만들어진 내용을 필드에 옮기고, 최종 게시/약관동의는 항상 사용자가 직접 클릭하는 절차 실행 단계다. 그래서 별도 서브에이전트 없이 스킬(절차 문서) 하나로 처리한다.

**요건**: 이 단계는 로컬 세션에 브라우저 조작 도구(예: MCP 브라우저 확장 등)가 설치돼 있다는 전제 없이도 실행 가능해야 한다. 있으면 활용하고, 없으면 체크리스트로 대체한다 (아래 4번).

## 진입

`.claude/skills/novel-publish/SKILL.md`를 호출한다.

## 절차

1. **게이트**: `project.yaml`의 `platform.verified`를 확인한다. `false`면 여기서 멈추고 사용자에게 "연재규칙이 미검증 상태입니다. 7단계(`novel-publish-assets`)를 다시 호출해 재검증해주세요"라고 안내하며 절차를 중단한다. 재검증 로직(재조사 시도 → 동의 게이트 → `project.yaml` 갱신)은 7단계에 이미 완비돼 있으므로 여기서 다시 만들지 않는다 — 8단계는 안내만 하고 7단계로 되돌린다.
2. `projects/<slug>/06-publish/essentials.md`(제목/소개글/태그/표지문구), `04-outline/platform-notes.md`를 읽는다.
3. 확정 플랫폼(`platform.confirmed`)에 접속한다(로그인은 사용자가 이미 되어 있다고 가정).
4. **필드 입력 (조건부)**:
   - 로컬 세션이 실제로 브라우저 조작 도구를 가지고 있다면, 세션이 직접 제목/소개글/태그/표지문구 등 입력 가능한 필드를 채운다. 표지 이미지처럼 세션이 다룰 수 없는 자산은 사용자가 직접 업로드하도록 안내한다.
   - 브라우저 조작 도구가 없다면, `essentials.md`의 필드값을 플랫폼 입력 폼 순서에 맞춰 정리한 체크리스트를 출력한다. 사용자가 그 체크리스트를 보고 직접 복사/붙여넣기 한다.
5. **최종 게시 버튼 클릭과 이용약관 동의는 항상 사용자가 직접 한다.** 세션(또는 체크리스트)은 이 지점 직전에서 멈추고 사용자에게 확인을 요청한다.
6. 사용자가 게시를 완료했다고 확인하면 `project.yaml`을 갱신한다: `stage_history`에 `stage: 8` 기록, `status: 9`. 실제 게시 URL이나 날짜가 있으면 `projects/<slug>/06-publish/publish-record.md`에 기록한다.

## 산출물
