# 3단계 — 플롯

## 목표

전체 아크와 회차별 비트 초안을 형식 제약 없이 확립하고, 이후 작품이 진행되는 동안(어느 단계의 세션에서든) 필요할 때마다 보완·수정 제안을 받아 사용자 승인 하에 반영한다. 세계관과 마찬가지로 한 번에 완벽한 설계를 기대하지 않는다 — 회차가 실제로 쓰이면서 계속 손볼 것을 전제로 한다.

## 초기설계 (Init)

### 입력
- `projects/<slug>/01-idea/synopsis.md` (1단계 시놉시스)
- `projects/<slug>/02-world/worldbuilding.md` (있는 만큼)

### 진행 방식
엄격한 절차를 강제하지 않는다. Claude/Codex 어느 쪽이 초안을 제안하든, 사용자가 직접 아크나 비트를 먼저 던지든 자유롭게 진행한다. 아래 최소요건만 충족하면 통과로 본다.

### 최소요건
`projects/<slug>/04-outline/plot.md`에 다음이 담겨 있어야 한다:
- 전체 아크 요약 1편 (기승전결 또는 3막 등, 형식은 자유)
- 최소 초반 10화 분량의 회차별 비트 초안 (각 회차의 핵심 사건 + 다음 화로 이어지는 훅 정도)

## 확장 (Update)

플롯도 세계관과 동일하게, 집필이 진행되며 계속 조정될 가능성이 높은 영역이다. 확장 절차는 3단계에만 묶여있지 않고, 프로젝트 진행 중 어느 단계의 세션에서든 호출할 수 있다.

### 트리거
- 사용자가 직접 "플롯을 수정/추가하고 싶다"고 요청
- 다른 단계의 세션(예: 집필 중인 세션)이 진행하다가 기존 비트로는 이어가기 어려운 전개가 필요하다고 판단했을 때
- 세계관 확장(03-world.md)으로 설정이 바뀌어 플롯 일부가 더 이상 맞지 않게 됐을 때

### 절차
1. 호출 세션이 `plot-architect-update` 서브에이전트를 부른다. 이 서브에이전트는 현재 `plot.md`와 (있다면) 계기가 된 맥락을 읽고, 아래 형식의 **제안만** 만들어 반환한다. 파일을 직접 수정하지 않는다.
   ```
   ## 제안: <한 줄 요약>
   - 왜 필요한가: ...
   - 무엇을 바꾸는가: <구체적으로 추가/수정할 회차 비트 또는 아크 내용>
   - 어디에 반영: plot.md의 어느 회차/섹션
   ```
2. 호출 세션은 이 제안을 사용자에게 그대로 보여주고 승인을 받는다. **승인 없이는 절대 파일을 수정하지 않는다.**
3. 승인을 받으면 호출 세션이 직접 `plot.md`를 수정하고, `projects/<slug>/04-outline/changelog.md`에 한 줄을 추가한다: `<날짜> — <요약> — <사유>`.

## 산출물

- `projects/<slug>/04-outline/changelog.md` (확장이 발생할 때마다 추가)
