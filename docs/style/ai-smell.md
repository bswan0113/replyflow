# AI 냄새 판정

6단계(집필)와 7단계(게시 필수요소)에서 생성된 텍스트가 기계적으로 쓰인 티가 나지 않도록 거치는 판정 절차. 두 단계 모두 이 문서의 점검 항목을 공유하지만, **판정 주체는 단계마다 다르다**:

- **6단계**: 활성 세션 자신이 판정한다 (6단계의 "단일 세션" 원칙 — 자기교정을 서브에이전트에 위임하지 않음).
- **7단계**: `publish-assistant` 서브에이전트가 판정해서 그 결과(통과/반려 + 근거)를 호출 세션에 반환한다. 재작성 여부와 재호출은 항상 호출 세션(=사용자와 대화 중인 쪽)이 결정한다 — `publish-assistant`가 내부에서 스스로 여러 번 도는 게 아니다.

**이 판정은 사후 외부검증 없는 자기평가라는 한계가 있다.** 그래서 아래처럼 반복 상한과 인용 근거를 강제해 최소한의 추적 가능성을 확보한다.

## 점검 항목

각 항목은 나쁜 예/좋은 예를 참고해 판단한다. 예시는 방향을 보여주는 것이지 금칙어 목록이 아니다 — 기계적으로 문구를 찾아 지우는 게 아니라 패턴 자체가 반복되는지를 본다.

1. **상투적 AI 어구 반복**: "그 순간", "왠지 모르게", "정적이 흘렀다" 같은 문구가 짧은 구간 안에서 여러 번 반복되는지.
   - 나쁜 예: "그 순간 그녀는 왠지 모르게 불안했다. 그 순간 모든 것이 달라 보였다."
   - 좋은 예: 같은 감정을 매번 다른 방식(행동, 대사, 감각 묘사)으로 표현.

2. **문장 리듬의 인위적 균일함**: 문장 길이가 기계적으로 일정하게 반복되는지.
   - 나쁜 예: 모든 문장이 15~20자 내외로 끊기며 비슷한 리듬으로 이어짐.
   - 좋은 예: 짧은 문장과 긴 문장이 의도적으로 섞여 긴장감/완급을 만듦.

3. **감정 라벨링 대신 묘사**: "그는 화가 났다"식 직접 서술만 있고 행동/디테일로 보여주지 않는지.
   - 나쁜 예: "그는 화가 났다."
   - 좋은 예: "그는 입을 다문 채 손에 쥔 잔을 내려놓았다. 소리가 필요 이상으로 컸다."

4. **대칭 구문 남발**: "~이지만 동시에 ~이기도 했다" 같은 균형잡힌 문장 패턴이 반복되는지.
   - 나쁜 예: 문단마다 "A했지만 동시에 B하기도 했다" 구조가 반복.
   - 좋은 예: 문장 구조를 다양화, 굳이 균형을 맞추지 않고 한쪽으로 치우친 서술도 사용.

5. **캐릭터별 말투 차별화 부족**: 모든 인물이 비슷하게 정돈된 문어체로 말하는지.
   - 나쁜 예: 모든 대사가 문법적으로 완결된 존댓말/평어로 균일함.
   - 좋은 예: 인물마다 말버릇, 문장을 끊는 방식, 어휘 수준이 다름.

6. **접속사/부사 반복**: "그러나", "결국", "마치 ~처럼" 같은 표현이 기계적으로 반복되는지.
   - 나쁜 예: 문단마다 "그러나"로 시작하는 문장이 있음.
   - 좋은 예: 접속 표현 없이도 문장 간 연결이 자연스럽게 읽힘.

## 판정 절차

1. 위 6개 항목을 하나씩 검토한다. 각 항목마다 **통과/반려와 함께 실제 인용문 근거**를 남긴다(어느 문장이 왜 걸리는지). 근거 없이 "통과"라고만 적지 않는다.
2. 하나라도 뚜렷하게 반려면 전체 판정은 **반려**. 전부 무난하면 **통과**.
3. 반려면, 지적된 항목이 걸린 부분만 겨냥해 다시 쓴다 — 전면 재작성이 아니라 걸린 지점 위주로 손본다.
4. 다시 1번으로 돌아가 재판정한다.
5. **최대 3회까지** 이 루프를 반복한다. 3회를 넘겨도 반려 항목이 남아있으면, 무한 반복하지 않고 사용자에게 명시적으로 묻는다: "자동 판정으로는 이 이상 개선이 어렵습니다. 현재 초고로 진행할지, 어느 부분을 직접 짚어주실지 알려주세요." 사용자의 답에 따라 진행 여부를 결정한다.
6. 통과(또는 3회 상한 후 사용자 승인)가 나기 전에는 다음 단계(6단계의 원고 저장, 7단계의 사용자 go/no-go)로 진행하지 않는다.

## 출력 형식

```
## AI 냄새 판정: 통과 / 반려 (N회차)
1. 상투적 AI 어구 반복: 통과/반려 — 근거(인용문)
2. 문장 리듬의 인위적 균일함: 통과/반려 — 근거
3. 감정 라벨링 대신 묘사: 통과/반려 — 근거
4. 대칭 구문 남발: 통과/반려 — 근거
5. 캐릭터별 말투 차별화: 통과/반려 — 근거
6. 접속사/부사 반복: 통과/반려 — 근거
```
