# 에세이 평가 루브릭

짧은 블로그 에세이(문예지·학술 논문이 아닌 개인 블로그 글) 초안을 평가하기 위한
고정 기준이다. 매번 새로 기준을 만들지 않고 이 문서를 그대로 재사용한다 —
평가자(사람이든 에이전트든)가 자기 글에 관대해지는 것을 막기 위한 장치다.

## 0. 적용 지침 (평가자가 반드시 지킬 것)

- **텍스트만 보고 평가한다.** 이 글이 왜/어떻게 쓰였는지, 몇 번째 퇴고인지, 필자가
  누구인지는 배제한다. 오늘 처음 이 글을 마주친 독자처럼 읽는다.
- **만점이 아닌 모든 점수에는 구체적 근거를 붙인다.** "그냥 괜찮음", "조금 약함" 같은
  막연한 코멘트는 금지. 어느 문장/문단을 가리키는지, 무엇이 부족한지, 어떻게 고치면
  나아지는지를 1~2문장으로 명시한다.
- 자기 자신(같은 에이전트)이 쓴 글이라도 예외 없이 동일한 기준을 적용한다.
- 항목 A, B, C는 서로 독립적으로 채점한다 — 문장이 좋다고 논지 점수를 관대하게
  주거나, 그 반대로 하지 않는다. 특히 C는 A/B가 아무리 높아도 별개로 채점한다.

## 1. 채점 항목

문장/논지 항목은 두 개만 쓴다. "구조/전개"를 별도 항목으로 떼지 않은 이유: 좋은
리듬·강한 도입부/마무리는 사실상 문장 단위 구조이고, 탄탄한 논리 전개는 사실상
논지 단위 구조라서, 별도 항목을 만들면 이미 있는 두 항목과 상당 부분 겹친다.

거기에 더해, A/B와 성격이 다른 세 번째 항목 하나를 둔다 — 품질과 별개로
"AI가 쓴 티가 나는가"를 거부권(veto)으로 따로 본다.

### 항목 A — 문장/글 품질
리듬, 명료성, 상투어·군더더기의 유무, 도입부와 마무리의 힘.

### 항목 B — 담론/논지 수준
주장이 진부하지 않은지, 근거-결론 논리가 성립하는지, 필자 고유의 시각이 있는지.

### 항목 C — AI 냄새 (거부권)
반복적인 수사 템플릿, 기계적으로 균일한 문단 구조, 상투적 전환어·메타발언,
과도하게 대칭적인 문장 짝 등 — 인간 필자 특유의 불규칙함 없이 예측 가능한
패턴이 글을 지배하는 정도. A/B 점수가 아무리 높아도 이 항목이 기준을 넘으면
자동 실패한다 (3절 참고).

구체적으로 아래 같은 패턴이 반복되는지를 근거로 삼는다 (하나만 있으면 정상적인
글쓰기 장치이지만, **같은 틀이 글 안에서 3회 이상 반복되면** AI 냄새로 센다):

- 동일한 대구/대조 수사 반복 (예: "A가 아니라 B다", "단순히 A를 넘어 B다" 류를
  섹션마다 다른 소재에 똑같은 틀로 반복)
- 문단마다 "주장 → 예시 나열(대개 3개) → 요약 문장"이 기계적으로 똑같이 반복
- 상투적 전환어("그런데", "하지만", "결국", "요컨대", "다시 말해")가 별다른
  이유 없이 문단마다 등장
- "~일 수도 있다", "~일지도 모른다" 같은 헤징 표현이 반복적으로 누적
- 매 섹션의 끝을 볼드체 한 문장으로 마무리하는 패턴이 규칙처럼 반복
- 메타발언("이 글에서는", "정리하자면", "결론적으로")이 반복 등장

## 2. 채점 척도: 1~5점

각 항목을 1~5점 정수로 채점한다. 앵커는 아래를 기준으로 삼는다 (정확히 일치하지
않으면 가장 가까운 설명에 맞춰 판단).

### 항목 A — 문장/글 품질

| 점수 | 앵커 |
|---|---|
| **1** | 비문이거나 뜻이 불분명한 문장이 다수. 문장 길이가 단조롭거나 뒤엉켜 리듬이 없음. 상투어·군더더기 수식어 반복. 도입부는 배경 설명으로 늘어지고, 마무리는 있으나마나 하거나 급작스럽게 끊김. |
| **2** | 문법적으로는 무난하지만 리듬이 단조롭고 상투어·군더더기가 눈에 띔. 도입부·마무리 중 하나가 약함. |
| **3** | 걸리는 곳 없이 매끄럽게 읽힌다. 문장 길이에 어느 정도 변화가 있고 상투어가 크게 거슬리지 않는다. 다만 인상에 남는 문장은 없음 — "무난하게 잘 쓴" 수준. 도입부·마무리 모두 기능은 하지만 특별히 강하지 않음. |
| **4** | 짧은 문장과 긴 문장을 의도적으로 섞은 흔적이 있고, 자기 목소리의 표현이 여러 군데 있음. 도입부 또는 마무리 중 적어도 하나가 뚜렷하게 힘 있음(바로 흥미를 끌거나 여운을 남김). |
| **5** | 문장 리듬이 의도적으로 설계됨. 상투어 없이 구체적·정확한 언어. 첫 문장이 바로 독자를 붙잡고, 마무리는 요약이 아니라 여운/재고를 남기며 끝남. 문단 전환이 매끄러움. |

### 항목 B — 담론/논지 수준

| 점수 | 앵커 |
|---|---|
| **1** | 주장 자체가 없거나(사실 나열/일기 수준) 지극히 뻔한 통념 재진술("노력하면 이루어진다" 류). 근거-결론 사이 논리적 비약이 큼. |
| **2** | 주장은 있으나 SNS·자기계발서에서 흔히 보는 진부한 논지. 근거가 얕거나 예시가 주장을 실제로 뒷받침하지 못함. |
| **3** | 주장이 명확하고 근거-결론 연결이 논리적으로 성립. 다만 관점 자체는 익숙한 범주 안 — 이미 여러 번 들어본 각도이고, 필자만의 시각이라 부를 지점이 약함. |
| **4** | 주장에 필자 고유의 관찰·각도가 최소 한 군데 있음(결론은 흔하더라도 거기 도달하는 근거나 경로가 새로움). 논리 전개에 비약·자기모순 없음. |
| **5** | 익숙한 접근에서 벗어난 독창적 관점이 글 전체를 이끎. 근거가 추상적 일반론이 아니라 구체적 사례/디테일. 있을 법한 반론도 논리적으로 처리됨. 다 읽고 나면 주제를 보는 시각이 살짝 바뀌거나 생각할 거리가 남는다. |

### 항목 C — AI 냄새

| 점수 | 앵커 |
|---|---|
| **1** | 위 패턴이 거의 안 보임. 문장 구조와 리듬에 예측 불가능한, 사람 특유의 변칙이 있음. |
| **2** | 한두 군데 스치듯 나타나지만 전체 흐름에서 튀지 않음. |
| **3** | 몇 군데 눈에 띄지만 글의 개성이 패턴에 묻히지는 않음. |
| **4** | 동일한 수사·구조가 글 안에서 3회 이상 반복돼, 그 패턴이 다음 문단에서도 나올 걸 예측할 수 있게 됨. |
| **5** | 처음부터 끝까지 템플릿화된 구조·수사가 지배적이라, 어느 문단을 펼쳐도 같은 틀이 보임. |

## 3. 총점 계산과 통과 기준

- **합계** = 항목 A + 항목 B (2~10점)
- **평균** = 합계 ÷ 2 (1~5점 척도로 표시)
- **항목 C는 합계·평균에 넣지 않는다** — 별도의 거부권으로만 작동한다.

**통과 조건 (전부 만족해야 함):**

1. 항목 A, B **모두 3점 이상** (한쪽이 뛰어나도 다른 쪽의 명백한 약점을 가리지 못하게 하는 최소선)
2. **평균 4.0점 이상** (합계 8점 이상)
3. **항목 C가 3점 이하** — 4점 이상이면 A/B 점수와 무관하게 자동 실패

| 조합 예시 (A, B, C) | A+B 합계/평균 | 결과 |
|---|---|---|
| (3, 3, 1) | 6 / 3.0 | 실패 (A/B 미달) |
| (4, 3, 2) | 7 / 3.5 | 실패 (A/B 미달) |
| (4, 4, 2) | 8 / 4.0 | 통과 |
| (5, 5, 1) | 10 / 5.0 | 통과 |
| (5, 5, 4) | 10 / 5.0 | **실패 (AI 냄새 거부권)** |
| (4, 4, 5) | 8 / 4.0 | **실패 (AI 냄새 거부권)** |

3점은 "매끄럽지만 인상에 남지 않는, 익숙한 각도" — 즉 전형적인 무난한 블로그
글의 기준선이다. A, B 모두 3점을 넘기지 못하면 실패하게 함으로써 "무난하기만
한" 글을 걸러내되, 두 항목 모두 만점까지 요구하지는 않는다. 항목 C는 A/B 점수가
아무리 완벽해도 반복적 AI 티가 심하면 통과시키지 않기 위한 별도 안전장치다.

## 4. 평가 출력 형식 (권장)

```
항목 A (문장/글 품질): X점 — [구체적 근거, 만점이 아니면 필수]
항목 B (담론/논지 수준): Y점 — [구체적 근거, 만점이 아니면 필수]
항목 C (AI 냄새): Z점 — [구체적으로 어떤 패턴이 몇 회 반복되는지, 3점 초과면 필수]
합계(A+B): X+Y / 평균: (X+Y)/2
결과: 통과 / 실패 (실패 사유: A/B 미달 또는 AI 냄새 거부권 중 명시)
```

## 5. 이 루브릭이 쓰이는 맥락 (참고, 루브릭 규칙 아님)

전체 게이트 흐름은 `GUIDE.md`의 집필 단계에 정의되어 있다: 초안을 이 루브릭으로
평가 → 통과하면 다음 단계로 진행. 실패하면 위에서 지적된 구체적 근거를 바탕으로
재작성한 뒤 다시 이 루브릭으로 평가한다. 평가-재작성을 3회 반복해도 통과하지
못하면 자동 루프를 멈추고, 그 초안과 지금까지의 평가 이력을 사용자에게 넘겨 최종
게시 여부를 사람이 직접 판단한다.

## 6. 이 루브릭의 개선

평가자는 평가 과정에서 이 루브릭 자체의 허점(기준이 모호함, 앵커가 변별력이
없음, 놓친 관점이 있음 등)을 발견하면 수정을 제안할 수 있다. 다만 **사용자
승인 없이 이 파일을 스스로 고치지 않는다** — 제안하고, 사용자가 승낙하면 그때
반영한다. 변경 이력은 별도 changelog 없이 git 커밋 이력으로 남긴다.
